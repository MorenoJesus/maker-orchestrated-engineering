# Delegation Contract

Status: draft. A task assignment cannot expand authority.

Record these items:

- delegation ID and revision
- authorized mission and policy revisions
- responsible executor
- objective
- permitted resources and actions
- environment
- inputs and immutable references
- expected outputs
- acceptance-condition IDs
- dependencies
- resource limits
- deadline
- retry limit
- escalation owner

Define stop conditions for ambiguity, scope change, unavailable access, unsafe content, contradictory evidence, budget exhaustion, and cancellation. State how partial output and unresolved issues are returned. Identify which agent or human owns shared contracts and integration.

## Communication guidance

Apply the organization's selected communication standard. ECS is this repository's default and an optional reference for adopters. Preserve exact identifiers and raw evidence. Distinguish facts, proposals, and unknowns. Use `not_run` only for known non-execution; otherwise use `unknown` when results are unavailable. See [the ECS profile](../profiles/communication-ecs.md).
