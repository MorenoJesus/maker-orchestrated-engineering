# Organization Profile

Profile ID, revision, owner, scope and date.

## Lifecycle mapping
Map Define, Contract, Orchestrate, Prove, Deliver and Learn to existing activities and states. Preserve existing responsibilities and clarify terminology.

## Core mapping
For C01-C10, identify local controls, systems of record, accountable owners, evidence and gaps. Disclose partial adoption.

## Governance
Risk classes; approval rights; data classes; retention; exception process; release controls; context and provider restrictions; cancellation and incident response.

## Implementation choices
Approved agents and tools; runtime boundaries; permitted concurrency; artifact formats; reviewer capacity; evidence sources; observation procedures.

## Evaluation
Pilot hypothesis, baseline, metrics, tolerances, stop conditions, reassessment triggers and known limitations.

## Communication guidance

Apply the organization's selected communication standard. ECS is this repository's default and an optional reference for adopters. Preserve exact identifiers and raw evidence. Distinguish facts, proposals, and unknowns. Use `not_run` only for known non-execution; otherwise use `unknown` when results are unavailable. See [the ECS profile](../profiles/communication-ecs.md).
