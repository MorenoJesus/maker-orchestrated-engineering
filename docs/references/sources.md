# Sources and related work

**Reviewed 2026-11-06.** The sources below provide context, not endorsement. MOE's normative requirements are original proposals. No external standard is claimed to certify this framework.

1. **Agile Manifesto.** Its emphasis on collaboration, working software, and adaptation informs MOE's decision to complement rather than dismiss existing practices. MOE does not reproduce the manifesto or claim Agile requires particular estimation or sprint practices. https://agilemanifesto.org/
2. **Scrum Guide, November 2020, official HTML edition.** Source for Scrum-specific accountabilities and commitments used in the illustrative profile. The profile is an original mapping, not a change to Scrum. https://scrumguides.org/scrum-guide.html
3. **GitHub, “Beyond code generation: A developer's guide to agentic engineering,” November 6, 2026.** Related industry framing across planning, building, verifying, and observing. MOE takes the lifecycle breadth as context; product claims and productivity statistics are not used as proof of MOE's effectiveness. https://github.blog/ai-and-ml/github-copilot/beyond-code-generation-a-developers-guide-to-agentic-engineering/
4. **NIST Secure Software Development Framework project.** Context for integrating secure development practices into different lifecycles. MOE does not claim SSDF conformance or select applicable regulatory requirements. https://csrc.nist.gov/projects/ssdf
5. **OWASP AI Agent Security Cheat Sheet.** Context for agent threat modeling, least privilege, tool restrictions, and human oversight. MOE's threat table is a proposed implementation starting point, not a complete audit. https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html
6. **JSON Schema Draft 2020-12.** Basis for the machine-readable reference contracts. The validator explicitly applies format checking and local schema resolution. Schema validity is distinct from semantic authorization and truth. https://json-schema.org/draft/2020-12

The draft does not rely on unverified headline statistics, promised ROI, current model rankings, or assumed vendor capabilities. Such claims require a dated source and an explicit explanation of their limits before inclusion.
