# Security reporting and public-content boundary

This repository is a framework draft and reference validator, not a hosted orchestration service.

Do not post credentials, private source code, customer data, exploitable details affecting another organization, or confidential incident material in public issues. The owner has not yet designated a private reporting channel. Before publishing sensitive details, request a private reporting route without including the sensitive payload.

Generic framework flaws and non-sensitive improvements can use public issues. Include the affected version, requirement, threat model, and a safe synthetic example. Do not claim a vulnerability in another product merely because an MOE reference example exposes a limitation.

Reference records contain synthetic identifiers. Replace them with controlled organizational records only in an appropriate private environment. The sample validator is not an authorization engine and must not be used as a production release gate without additional design and review.
